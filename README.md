Aula 01 | Terça [01/09/26] 
Curso: Ciência de Dados 
Componente: Desenvolvimento de Sistema Aplicados a Dados 
Aluna: Lúcia Camila Carvalho de Oliveira 
 

Nome da Squad: Solar Tech  
Escopo do Sistema. 


 
Requisitos Funcionais (RF) 
	O sistema deve permitir: 
	1- Que o usuário ligue e desligue, por meio de automação, aparelhos eletrônicos; 
	2- Que o usuário baixe arquivos com dados de geração de consumo de energia renovável por períodos (dia, mês, ano); 
	3- Que o usuário marque a manutenção dos aparelhos de energia; 

 
Requisitos Não-Funcionais (RNF)  
	O sistema deve: 
	1- Validar os dados de consumo corretamente de forma rápida e precisa; 
	2- Gerar arquivos com dados de consumo automaticamente, com interface simples;
